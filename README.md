# Ghenolife — Prototype Android Godot + LLM mock

Branch: prototype/android-godot-llm-skeleton

Objectif
- Squelette Godot (2D) prêt pour export Android (APK) avec un LLM mock local (GDScript) pour prototyper les dialogues.
- Instructions pour construire l'APK et notes sur l'intégration future d'un LLM local (llama.cpp / GGUF / TGI).

Contenu
- /godot : projet Godot minimal (scene + scripts + project.godot)
- /android : instructions pour préparer l'export Android

Remarques
- Tous les personnages et contenus doivent être 18+ si vous prévoyez du contenu adulte.
- Le LLM réel (modèle quantifié) n'est pas inclus dans le dépôt pour limiter la taille. Fournir les poids séparément et suivre les instructions du dossier /android pour les intégrer.

Voir /godot pour démarrer.
